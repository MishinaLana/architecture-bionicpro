# Запуск
1. В корневой папке запутить команду ```docker compose up -d```
2. Перейти в папку Task2 ```cd Task2```
3. Запустить проект внутри этой папки ```docker compose up -d``` и дожидаемся запуска всех сервисов

# Настройка

Настройка подключения к Postresql в Airflow

1. Заходим по адресу http://localhost:8085/
2. Добавляем новое подключение на странице http://localhost:8085/connection/list/

# Наполнение БД postgresql и clickhouse
1. Перейти на страницу http://localhost:8085/home
2. Сначала выполняем clients_to_postgres_dag
3. Затем выполняем загрузку телеметрии в clickhouse: запускаем telemetry_import

На шаге 3 загрузятся клиенты
На шаге 4 будут загружаться данные телеметрии дополняясь данными по клиенту

# Получение отчета

1. Открыть страницу http://localhost:3000/ и нажать кнопку Login
2. На открывшейся странице ввести логин: user1@example.com и пароль: password123
3. Нажать кнопку Download Report
4. Запустится процесс генерации отчета из click house и файл отчета начнет скачиваться в браузере
